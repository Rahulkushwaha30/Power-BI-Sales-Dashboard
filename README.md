Sales Performance Dashboard — Power BI

Total Sales KPI card

Sales analysis by region

Product-wise sales performance

Customer-wise sales analysis

Professional dashboard layout and formatting

Tools Used

Microsoft Power BI

Power Query

Data Modeling

Data Visualization

To present sales data in an interactive dashboard that helps users explore sales performance across different business categories.
